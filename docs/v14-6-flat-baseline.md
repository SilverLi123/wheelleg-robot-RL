# V14-6 平地基线复现

这条分支从队友已评测的平地策略出发。第一步只复现平地；独立任务骨架和旧的 5100 续训入口不用于本次复现。

| 用途 | 选择 |
| --- | --- |
| 平地参考与候选初始化 | `flat_seed42 / model_2000.pt`，队友按共同平地评分保留的候选。原训练文件、本地归档候选、原评测记录中的权重 SHA-256 一致。 |
| 暂停恢复点 | `model_5100.pt`，保存了当时的 PPO 状态。训练迭代号更高，原评测并未据此选它替换 2000。 |
| 复杂地形对照 | 队友当前统一地形分支，单独保留。比较时固定地形、指令、时长和随机种子。 |

源工作区是 pi 上的 `/data/wheelbipe-v14-6-training-20261108`。对应原评测在其 `evaluation/flat_seed42/iteration_2000/own_domain`。历史评测轨迹已用原 `tools/assess.py` 重新计分，结果与存档一致：8 个环境各 6 秒，均无终止、超时或异常；稳态前向速度、偏航角速度平均绝对误差分别为 **0.01105 m/s**、**0.01180 rad/s**，闭链残差峰值 **0.107 mm**。这是对存档的重算。

在 **Mac 的仓库根目录**运行：

```bash
bash scripts/reproduce_v14_6_flat.sh 4
```

参数是 GPU 编号。加 `--check` 可只做只读预检。正式回放前也会检查所选卡；空闲检查是一次采样，不能预留 GPU。脚本在 pi 上只读队友的源项目、权重和配套配置，调用原 `evaluate_grid.py` 和 `assess.py`。本次评测的独立输出目录会打印到终端，放在 `/data/wheeled-legged/logs/v14_6_flat_2000_*`。

输入是原权重和种子 `20261108`。八条指令覆盖站立、前进、后退和左右转；保持原 35 维 Actor 观测、78 维 Critic 观测、6 维动作与 400 Hz 物理、50 Hz 策略。评测只做推理，不更新模型。预检核对保存的项目和资产指纹；唯一已知源码差异是闭链异常采集模块，复现脚本单独锁定其当前版本。共享框架核对已安装版本，未声称框架源码逐字节一致。

查看 `summary.json` 和 `metrics.json`：预期 `PASS`、300 个策略步、2400 个物理步、数值有限、力矩检查通过、8 个环境都不复位。拿新结果与上面的误差及闭链峰值比较；若偏差明显，先检查实际物理参数、资产和回放配置。新仿真结果尚待执行。

平地复现通过后，先在队友已有统一地形代码上做轻坡上行、下行与平地的冻结策略对照。核对观测字段的顺序、单位、缩放和动作映射，也核对地形切换后高度等字段的语义；维数相同不能证明权重可直接迁移。通过后复用队友的初始化入口，用平地权重开启新 PPO 实验并重新初始化 Adam；保留平地样本和独立评估。若 Critic 的输入或回报定义发生实质变化，再考虑现有的 `--actor_only_finetune`。坡面修改和训练留待本步 Review。
