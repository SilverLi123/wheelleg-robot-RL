# RoboMaster 赛场轮腿机器人技术评价标准与对标基线

> **文档用途**：作为 `wheelleg_lab` 项目后续训练、评估与控制优化的工程参考标尺。  
> **参考来源**：RoboMaster 超级对抗赛（RMUC）场地/规则规范（斜坡、二级台阶、高地、裁判系统功率限制）及开源社区顶尖轮腿战队（华南虎、交龙、SuperPower 等）工程评审维度。  
> **当前对标基线模型**：`dirD2_model_5`（400 Hz 物理步长 `WHEELBIPE_INTEGRATION_SUBSTEPS=2`，35 维纯本体感知策略）。

---

## 一、 轮腿机器人在 RoboMaster 赛场上的四大核心作用

在 RoboMaster 赛场上，轮腿/平衡步兵的定位不是单一地形的缓慢移动平台，而是**「高机动突击手 + 全地形奇兵 + 移动稳定火力点」**：

1. **移动稳定火力输出平台（云台解耦与抗震）**
   - **战术作用**：在上下坡、冲下台阶或碾压散落弹丸时，底盘（轮 + 腿）作为主动悬架吸收地形冲击，保证上层云台（Pitch / Yaw 轴）不触碰机械限位、视觉自瞄锁敌不丢帧、边跑边打保持高命中率。
   - **底线要求**：底盘/装甲板不托底刮擦，云台与机身姿态波动被严格限制在可控范围内。

2. **全地形绕后与战术抢点（陡坡、跳台与飞坡）**
   - **战术作用**：开辟传统全向轮/麦轮步兵因底盘离地间隙不足而无法通行的奇袭路线，快速登上高地/资源岛或从高台跳落反打侧翼与后背。
   - **典型官方地形参数**：
     - **连续斜坡**：公路坡、启动区及高地坡常见为 **`15° ~ 17°`**（对应坡度约 **`26.8% ~ 30.6%`**），边界局部坡度更陡。
     - **下台阶 / 跳高地**：从高地或二级台阶跳下/滚下，单级台阶落差常见 **`100 ~ 200 mm`**，连续台阶总落差 **`200 ~ 400 mm`**。
     - **飞坡与垂直上台阶**：高速飞坡缓冲落地，或通过主动抬腿/蓄力跳跃登上 **`100 ~ 200 mm`** 台阶与障碍台。

3. **高机动转移与战场生存（冲刺、急起停与小陀螺）**
   - **战术作用**：在平地与公路区发挥轮式极速优势抢占先手位置，进入交火区后高频变向、急起急停并配合底盘高速「小陀螺」旋转躲避敌方自瞄弹道，同时保持平衡。

4. **裁判系统功率合规与极限自救（生存底线）**
   - **规则约束**：步兵底盘受 **`60 W ~ 120 W`** 裁判系统实时功率限制（需结合超级电容爆发）；高烈度冲坡、下台阶、压散落 `17 mm / 42 mm` 弹丸或被敌方冲撞侧翻后，需能通过腿部支撑实现倒地自救、快速重返战场。

## 二、 RoboMaster 轮腿机器人量化评价标准（分级标尺）

下表按 **工程验证及格线（C / B 级）**、**强队赛场实战线（A 级）**、**顶尖开源标杆线（S 级）** 三个档位给出可量化的训练与评估判据：

| 评价维度 | 关键评价指标 | C / B 级（工程可用 / 基础及格线） | A 级（RM 强队赛场实战线） | S 级（顶尖开源战队标杆线） |
| :--- | :--- | :--- | :--- | :--- |
| **1. 姿态稳定与云台解耦** | 复杂地形行进中机身 `\|pitch\|`、`\|roll\|` 与云台最小离地间隙 | 平地与缓坡 `\|pitch\|, \|roll\| <= 6°`；连续越障不触地、零机械奇异或闭环超限 | 过坡与连续下台阶 `max\|pitch\| <= 5°`、`max\|roll\| <= 3°`；机身/云台最小离地间隙充足，无托底撞击 | 剧烈越障及高速急停时机身姿态波动 `<= 3°`，下台阶几乎无明显回弹/摇头，云台自瞄完全无感 |
| **2. 下台阶与跳台落地缓冲** | 可通过单级台阶高、连续总落差、触地回弹抑制及着陆成功率 | 单级 `30 ~ 70 mm` 连续下台阶稳定不翻车；落地不触发过流/硬件崩溃 | 单级 `80 ~ 150 mm`（总落差 `>= 250 ~ 360 mm`）达台率 `>= 95%`，伸腿探底+屈腿吸能平滑，触地后正回弹竖直速度 `vz` 小 | 单级 `150 ~ 200 mm` 跳台及高速飞坡落差 `> 80% ~ 95%` 软着陆成功率，落地 `0.15 s` 内回稳并保持高巡航速度 |
| **3. 连续斜坡与坡道过渡** | 最大可爬/下坡度、坡顶/坡底折角适应性与速度/航向误差 | 稳定通过 `±10°`（`±18%`）以内连续斜坡与常见折角，零倾覆 | 稳定通过 **`15° ~ 17°`（`27% ~ 30%`）** RM 标准公路坡，上下坡及斜角入坡不抬头、不溜车，跟踪误差可控 | `>= 17° ~ 20°`（`30% ~ 36%`）陡坡与复合非结构地形全向高速上下，几乎无速度跌落 |
| **4. 机动速度与转向敏捷度** | 最高线速度 `vx`、偏航角速度 `wz`、急起急停与小陀螺稳定性 | 巡航 `0.5 ~ 1.0 m/s`，转向 `\|wz\| <= 0.5 rad/s`，适合中低速路线跟踪 | 平地/缓坡 **`1.5 ~ 2.5 m/s`**，快速转向 **`\|wz\| >= 1.5 ~ 2.5 rad/s`**，急刹抑制前倾点头，可低速小陀螺 | 平地冲刺 **`3.0 ~ 5.0 m/s`**，高速小陀螺 **`wz = 3.0 ~ 10.0 rad/s`** 同时稳定叠加平面移动与越障 |
| **5. 上台阶与主动跳跃越障** | 不借助斜面登高高度（滚动越障 / 主动跳跃） | 纯滚动稳定通过 `25 ~ 35 mm` 低凸起与场地接缝，不因单轮异步触阶侧翻 | 主动蓄力抬腿或单步小跳登上 **`60 ~ 120 mm`** 台阶（成功率 `>= 80%`） | 一键蓄力跳跃或前后轮协同跨栏式登上 **`150 ~ 200 mm`** 公路台阶 / 二级台阶 |
| **6. 抗扰与底层安全约束** | 碎障/撞击恢复、连杆闭环误差与裁判系统功率约束 | 碾压 `17 mm` 弹丸量级凸起不失稳；400 Hz 仿真闭环误差 `< 2 mm` | 压 `17 mm / 42 mm` 弹丸与中等侧向撞击不摔；满足瞬时力矩与能量预算约束，不长期超功率 | 任意姿态倾覆后可自主「鲤鱼打挺」复位；显式满足 `60~120 W` 功率上限策略调度 |

## 三、 当前项目基线（`dirD2_model_5`）对标评估结论

根据本阶段在 400 Hz 物理仿真（`dt = 0.0025 s`，`policy_dt = 0.02 s`，Domain Randomization 开启）下的全量测试与连续实录数据，对当前冠军模型 `dirD2_model_5` 逐项定级如下：

| 评估维度 | 当前实测证据 | 对标评级 | 工程评估要点 |
| :--- | :--- | :---: | :--- |
| **下台阶与云台解耦姿态** | 3 种子 `stairs_down_{30,60,90}mm` **`27/27 (100%)`** 生存并到达着陆台（`90 mm` 时 `min_base = 0.0091 m`）；`70 mm × 4` 连续下楼实录全程 `max\|pitch\| = 3.63°`、`max\|roll\| = 2.12°`、`vx_mae = 0.0313 m/s`、`resets = 0` | **A 级（优秀）** | 已自动涌现「伸腿探底 → 屈腿压缩吸能（`0.254 m -> 0.220 m`）→ 回稳」悬架动作；仅存在触地后轻微回弹（`vz ≈ +0.27 ~ +0.32 m/s`）及约 `1.5° ~ 2.0°` 常值左倾偏置待精修 |
| **多坡度适应与坡面过渡** | 3 种子 3×3 随机坡面（`±6%, ±10%, ±14%, ±18%`）**`81/81 (100%)`**（`vx_mae = 0.0133 m/s`、`wz_mae = 0.0229 rad/s`、`min_gimbal = 0.2585 m`）；24 种合法跨块过渡 **`24/24 (100%)`**（`vx_mae = 0.01650 m/s`、`min_base = 0.0090 m`）；270 s（`13,500` 步）蛇形走廊全 `9/9` 航点 **`resets = 0`** | **B+ 级（扎实）** | `±18%`（约 `±10.2°`）以内的坡面组合与折角过渡控制精度极高、无托底；尚待冲击 RM 赛场典型的 `15° ~ 17°`（`27% ~ 30%`）长陡坡 |
| **碎障与低凸起抗扰** | `30~90 mm` 向下突变 `100%` 通过；盲走 `platform_up_25mm` 仅 `1/3` 登顶（另 `2/3` 侧倾重置），`platform_up_40mm` `2/3` 直立未倾覆、`0/3` 达台 | **B 级（分化明显）** | 向下抗扰强、向上滚障对双轮异步接触滚转极敏感；满足 `17 mm` 小弹丸级别碾压，对 `42 mm` 大弹丸级凸起仍需加固滚转抑制 |
| **机动速度与转向敏捷** | 训练与实录固定在低速巡航 **`0.65 m/s`**、转向 **`\|wz\| <= 0.45 rad/s`** | **C 级（工程验证档）** | 速度/航向跟踪误差 `< 0.028 m/s` / `< 0.037 rad/s`，但尚未覆盖 RM 实战所需的 `1.5 ~ 4.0 m/s` 中高速冲刺、急起停与小陀螺工况 |
| **垂直上台阶越障能力** | `platform_up_{60,120,180}mm` 盲走纯滚动 `0/27` 达台（受 `62.5 mm` 轮半径、前/底导杆碰撞包络及无高程观测限制） | **D 级（当前短板）** | 双轮并列结构仅靠纯轮速无法跨越 `>= 60 mm` 垂直立面，必须通过主动跳跃模态或前视感知打破物理上限 |

## 四、 面向 RoboMaster 实战标准的后续演进路线图

按收益与工程可执行性排列后续研发优先级：

1. **P0 — 速度与转向扩域（从「低速稳态」升级到「中高速敏捷」）**
   - 将指令速度范围从固定 `0.65 m/s` 扩展为连续采样（如 `vx ∈ [-1.0, 2.0+] m/s`、`wz ∈ [-2.0, +2.0] rad/s`），增加阶跃加减速指令以抑制急起/急停点头，验证小陀螺连续自转叠加平动能力。
2. **P1 — 坡度基准升级至 RM 赛场标准陡坡（`15° ~ 17°` / `27% ~ 30%`）**
   - 在现有 3×3 地图（最高 `18%`）基础上扩展 `25% ~ 30%` 陡坡评估与微调场景，同时在审计指标中纳入关节扭矩饱和率与等效机械功率估计（对接裁判系统功率限制）。
3. **P2 — 下台阶与低凸起姿态精修（对标 A+/S 级云台稳定性）**
   - 针对当前 `70 mm` 下楼轨迹的精细化诊断结果：加入**左右腿对称约束**以消除 `-1.5° ~ -2.0°` 常值横滚偏置；加强下落触地后向上的**正向竖直速度阻尼惩罚**，消除 `+0.27 ~ +0.32 m/s` 回弹颠簸，同时提升 `25~40 mm` 低凸起双轮异步接触时的滚转鲁棒性。
4. **P3 — 主动跳跃模态（解锁 `100 ~ 200 mm` 上台阶能力）**
   - 参考顶尖战队强化学习方案，引入「命令驱动跳跃（蓄力深蹲 → 爆发伸腿起跳 → 空中收腿 → 落地主动缓冲）」独立阶段奖励，或接入前端高程/深度局部观测，突破纯滚动翻越垂直台阶的物理极限。
